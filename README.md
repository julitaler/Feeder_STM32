# Контроллер автоматической кормушки (Ada/STM32)

Проект реализует логику работы автоматической кормушки на базе микроконтроллера **STM32F411CEU6** (WeAct BlackPill), написанную на языке **Ada**.

## Функционал

Контроллер работает в циклическом режиме:
1.  **Режим кормления (Feeding):**
    *   Длительность: **10 секунд**.
    *   Действие: Светодиод (LED) включен.
    *   UART вывод: Статус `"Feeding..."`.
2.  **Режим ожидания (Idle):**
    *   Длительность: **19 минут 50 секунд**.
    *   Действие: Светодиод выключен.
    *   UART вывод: Статус `"Idle..."`.

**Общий цикл:** 20 минут.

## Аппаратная часть

*   **Плата:** WeAct Studio BlackPill (STM32F411CEU6).
*   **Светодиод:** Встроенный LED на порту **PC13**.
*   **UART:** USART1 (TX на PA9, RX на PA10).
    *   Скорость (Baudrate): 115200.
    *   Параметры: 8N1 (8 бит данных, нет четности, 1 стоп-бит).
    *   Управление потоком: Отсутствует.

## Сборка и запуск

Для сборки проекта требуется установленный инструментарий GNAT для ARM и файл проекта `.gpr`.

### Требования
*   GNAT Toolchain for ARM (`arm-eabi-gcc`, `gprbuild`).
*   Ada Drivers Library (ADL) или соответствующие HAL-пакеты.

### Команда сборки
Находясь в корневой директории проекта:

```bash
gprbuild --target=arm-eabi -d -Pdefault.gpr
```

> **Важно:** Убедитесь, что путь к проекту не содержит кириллических символов или пробелов, чтобы избежать ошибок `gprbuild`.

### Прошивка
Полученный бинарный файл загружается на плату через ST-Link/V2 или DFU-загрузчик.

## Структура кода

*   `src/main.adb`: Точка входа и основной цикл программы.
    *   `Delay_Ms`: Процедура задержки в миллисекундах.
    *   `USART1_Send_String`: Процедура отправки строки в последовательный порт.
    *   Основной цикл `loop`: Реализует тайминги и переключение состояний.

## Логика работы

```text
[Start]
   |
   +---> [Feeding Mode] (10 sec)
   |       - LED: ON
   |       - UART: "Feeding..."
   |
   +---> [Idle Mode] (19 min 50 sec)
   |       - LED: OFF
   |       - UART: "Idle..."
   |
   +---> (Repeat)
```
